This is a cloned repository of the TMSi python interface that includes reader files for the CMU OMEGA project. 

The files included specifically for this project are under the "OMEGA" folder. 

Within this folder there are two files: 

1. A batch converter for poly5 and poly6 file types that changes these files into a CSV

2. A metadata reader that extracts existing metadata from poly5/6 data recordings, and allows for the user to input xy coordinates for grid placements, as well as orientation of the grid relative to the stem going left, as shown in the TMSi poly6 SPIRE user manual.
